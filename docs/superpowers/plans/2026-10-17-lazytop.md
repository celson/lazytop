# lazytop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `lazytop`, a Rust TUI system monitor for macOS (Apple Silicon) and Linux with a SiliconScope-like dashboard (CPU E/P, GPU/ANE/Media, memory + bandwidth, network + disk, sensors, processes, power, local-AI overview).

**Architecture:** A collector thread builds an immutable `Snapshot` every interval (common `sysinfo` data + a platform backend: IOReport/SMC/IOKit on macOS, `/sys` + `/proc` + NVML on Linux) and sends it over an `mpsc` channel. The UI thread (ratatui + crossterm) owns `App` state, keeps `History` ring buffers and renders OS-agnostic panels. Every platform metric is `Option` and renders as `—` when missing.

**Tech Stack:** Rust 1.99.1 (pinned via mise), ratatui 0.30, crossterm 0.29, sysinfo 0.39, clap 4.6, serde 1, toml 1.1, anyhow 1, dirs 7, libc 0.2, core-foundation 0.10 (macOS), nvml-wrapper 0.13 (Linux), tempfile 3 (dev).

**Spec:** `docs/superpowers/specs/2026-10-17-lazytop-design.md`

## Global Constraints

- Platforms: macOS Apple Silicon and Linux x86_64/aarch64; **no root required** for any feature.
- Every platform-specific metric is `Option`; missing → `—` or hidden panel; the app never panics because a source is unavailable.
- Sampling never blocks keyboard input; default interval 1000 ms; `+`/`-` clamp to 250 ms – 10 s.
- lazytop's own CPU use < 2 % of one core at 1 s on an M3 Pro.
- Config at `~/.config/lazytop/config.toml` (use `dirs::config_dir()` on Linux; on macOS use `$HOME/.config/lazytop/config.toml`); CLI flags override config; invalid config → message on stderr and exit code 2.
- Errors from sources are logged once per source to `--log <file>`; never drawn into the TUI.
- Terminal must always be restored (normal exit, error, panic).
- `--demo` runs anywhere with synthetic deterministic data.
- Out of scope: record/replay, fleet/remote, Windows, signals other than SIGTERM/SIGKILL.
- Linux GPU: first GPU only.
- Release assets for darwin/linux × arm64/amd64, installable with `mise use github:celson/lazytop`.
- All commands run through mise: prefix with `mise exec --` (or have mise activated in the shell). Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **First sample / zero dt** — the first snapshot has no previous counters, and two samples can arrive with dt≈0: rates, watts and usage must be `None`/0, never NaN/inf/huge. (Tests: Task 2 `Counter`, Task 8 `watts_from_energy`.)
2. **Counter reset / wraparound** — interface byte counters dropping (interface restart) and RAPL energy wrapping at `max_energy_range_uj` must not produce negative or enormous rates. (Tests: Task 2 `counter_reset_yields_zero`, Task 6 `rapl_wraps`.)
3. **Tiny terminal** — 30×8 or a resize to 1×1 must not panic; show "terminal too small". (Test: Task 14 `tiny_terminal_does_not_panic`.)
4. **Process list churn** — the selected process exiting between refreshes, or a filter that matches nothing, must keep selection valid (clamped) and `k` on an empty list is a no-op; kill of an already-dead pid shows "no such process". (Tests: Task 13 `selection_follows_pid_and_clamps`, `kill_on_empty_list_is_noop`, `esrch_message`.)
5. **Unicode / long names** — process names and sensor labels with multi-byte chars or longer than the column must be truncated by display width without panicking on char boundaries. (Test: Task 11 `truncate_handles_multibyte`.)

```rust
impl Counter {
    pub fn new() -> Self {
        Self::default()
    }

    /// Returns units/second since the previous call, `None` on the first call or dt == 0.
    /// A counter that went backwards (reset) yields `Some(0.0)` and rebases.
    pub fn update(&mut self, value: u64, now: Instant) -> Option<f64> {
        let out = match self.prev {
            None => None,
            Some((pv, pt)) => {
                let dt = now.saturating_duration_since(pt).as_secs_f64();
                if dt <= 0.0 {
                    return None; // keep previous base
                }
                Some(value.saturating_sub(pv) as f64 / dt)
            }
        };
        self.prev = Some((value, now));
        out
    }
}
```

```rust
impl History {
    pub fn new(cap: usize) -> Self {
        Self { cap: cap.max(1), data: HashMap::new() }
    }

    fn put(&mut self, s: Series, v: f64) {
        if !v.is_finite() {
            return;
        }
        let q = self.data.entry(s).or_default();
        if q.len() == self.cap {
            q.pop_front();
        }
        q.push_back(v);
    }

    pub fn push(&mut self, s: &Snapshot) {
        for c in &s.cpu.clusters {
            let series = match c.kind {
                ClusterKind::Efficiency => Series::CpuE,
                ClusterKind::Performance => Series::CpuP,
                ClusterKind::All => Series::CpuAll,
            };
            self.put(series, c.usage);
        }
        if s.cpu.clusters.is_empty() {
            self.put(Series::CpuAll, s.cpu.total);
        }
        if let Some(g) = &s.gpu {
            self.put(Series::Gpu, g.usage);
        }
        if let Some(b) = &s.bandwidth {
            self.put(Series::Bandwidth, b.total);
        }
        if s.mem.total > 0 {
            self.put(Series::MemUsed, s.mem.used as f64 / s.mem.total as f64);
        }
        self.put(Series::NetRx, s.net.rx);
        self.put(Series::NetTx, s.net.tx);
        if let Some(r) = s.disk.read {
            self.put(Series::DiskRead, r);
        }
        if let Some(w) = s.disk.write {
            self.put(Series::DiskWrite, w);
        }
        for g in &s.sensors {
            let series = match g.kind {
                SensorKind::Cpu => Series::TempCpu,
                SensorKind::Gpu => Series::TempGpu,
                SensorKind::Battery => Series::TempBattery,
                _ => continue,
            };
            if let Some(avg) = g.avg() {
                self.put(series, avg);
            }
        }
    }

    pub fn points(&self, s: Series) -> Vec<(f64, f64)> {
        self.data
            .get(&s)
            .map(|q| q.iter().enumerate().map(|(i, v)| (i as f64, *v)).collect())
            .unwrap_or_default()
    }

    pub fn last(&self, s: Series) -> Option<f64> {
        self.data.get(&s).and_then(|q| q.back().copied())
    }

    pub fn max(&self, s: Series) -> f64 {
        self.data
            .get(&s)
            .and_then(|q| q.iter().copied().reduce(f64::max))
            .unwrap_or(0.0)
    }

    pub fn capacity(&self) -> usize {
        self.cap
    }
}
```

```rust
//! Minimal file logger. Without `init` everything is dropped (never printed to the TUI).
use std::collections::HashSet;
use std::fs::File;
use std::io::Write;
use std::path::Path;
use std::sync::{Mutex, OnceLock};

static FILE: OnceLock<Mutex<File>> = OnceLock::new();
static SEEN: OnceLock<Mutex<HashSet<String>>> = OnceLock::new();

pub fn init(path: &Path) -> std::io::Result<()> {
    let f = File::create(path)?;
    let _ = FILE.set(Mutex::new(f));
    Ok(())
}

fn seen_set() -> &'static Mutex<HashSet<String>> {
    SEEN.get_or_init(|| Mutex::new(HashSet::new()))
}

/// Logs `msg` the first time `source` reports a problem; later calls are ignored.
pub fn warn_once(source: &str, msg: &str) {
    let first = seen_set().lock().map(|mut s| s.insert(source.to_string())).unwrap_or(false);
    if first {
        info(&format!("WARN [{source}] {msg}"));
    }
}

pub fn seen(source: &str) -> bool {
    seen_set().lock().map(|s| s.contains(source)).unwrap_or(false)
}

pub fn info(msg: &str) {
    if let Some(f) = FILE.get()
        && let Ok(mut f) = f.lock()
    {
        let _ = writeln!(f, "{msg}");
    }
}
```

```rust
pub fn spawn(mut c: Box<dyn Collector>, interval: Duration) -> (Receiver<Snapshot>, Sender<Control>) {
    let (tx, rx) = mpsc::channel();
    let (ctl_tx, ctl_rx) = mpsc::channel();
    thread::Builder::new()
        .name("lazytop-collector".into())
        .spawn(move || {
            let mut interval = interval;
            let mut paused = false;
            loop {
                let started = Instant::now();
                if !paused && tx.send(c.sample()).is_err() {
                    return;
                }
                // Sleep for the rest of the interval, waking up on control messages.
                loop {
                    let wait = interval.saturating_sub(started.elapsed());
                    match ctl_rx.recv_timeout(wait) {
                        Ok(Control::Quit) | Err(RecvTimeoutError::Disconnected) => return,
                        Ok(Control::Pause(p)) => paused = p,
                        Ok(Control::SetInterval(d)) => interval = d,
                        Err(RecvTimeoutError::Timeout) => break,
                    }
                    if !paused && started.elapsed() >= interval {
                        break;
                    }
                }
            }
        })
        .expect("spawn collector thread");
    (rx, ctl_tx)
}
```

```rust
pub fn model_budget_b(usable_bytes: u64) -> Option<u32> {
    let params_b = usable_bytes as f64 / BYTES_PER_PARAM / 1e9;
    SIZES_B.iter().rev().find(|s| **s as f64 <= params_b).copied()
}

fn level(active: bool) -> EngineState {
    if active { EngineState::Active } else { EngineState::Idle }
}

pub fn analyze(s: &Snapshot) -> AiStats {
    let runtimes: Vec<AiRuntime> = s
        .procs
        .iter()
        .filter(|p| {
            let n = p.name.to_lowercase();
            RUNTIME_PATTERNS.iter().any(|pat| n.contains(pat))
        })
        .map(|p| AiRuntime { name: p.name.clone(), pid: p.pid, cpu: p.cpu, mem: p.mem })
        .collect();

    let gpu_usage = s.gpu.as_ref().map(|g| g.usage).unwrap_or(0.0);
    let ane_w = s.power.as_ref().and_then(|p| p.ane_w).unwrap_or(0.0);
    let media = s.bandwidth.as_ref().map(|b| b.media).unwrap_or(0.0);
    let engines = Engines {
        cpu: level(s.cpu.total > 0.10),
        gpu: level(gpu_usage > 0.10),
        ane: level(ane_w > 0.1),
        media: level(media > 0.1e9),
        mem: if s.mem.pressure.unwrap_or(0.0) > 0.5 { EngineState::Elevated } else { EngineState::Normal },
    };

    let top_proc = s
        .procs
        .iter()
        .max_by(|a, b| a.cpu.total_cmp(&b.cpu))
        .map(|p| (p.name.clone(), p.cpu));

    let busy = runtimes.iter().any(|r| r.cpu > 10.0) || (!runtimes.is_empty() && gpu_usage > 0.10);

    let usable = match &s.gpu {
        Some(GpuStats { mem_total: Some(t), mem_used, .. }) => t.saturating_sub(mem_used.unwrap_or(0)),
        _ => ((s.mem.total as f64 * 0.75) as u64).saturating_sub(s.mem.used),
    };

    AiStats { runtimes, top_proc, engines, busy, budget_b: model_budget_b(usable) }
}
```

```rust
pub fn merge(mut s: Snapshot, pd: PlatformData) -> Snapshot {
    if let Some(chip) = pd.chip {
        s.host.chip = chip;
    }
    s.host.cores_e = pd.cores_e;
    s.host.cores_p = pd.cores_p;
    s.cpu.clusters = if pd.clusters.is_empty() {
        vec![CpuCluster { kind: ClusterKind::All, usage: s.cpu.total, mhz: None }]
    } else {
        pd.clusters
    };
    s.gpu = pd.gpu;
    s.power = pd.power;
    if let Some(m) = pd.mem {
        s.mem.used = m.used;
        s.mem.free = m.free;
        s.mem.wired = Some(m.wired);
        s.mem.active = Some(m.active);
        s.mem.compressed = Some(m.compressed);
        s.mem.app = Some(m.app);
        s.mem.cached = Some(m.cached);
        s.mem.pressure = m.pressure;
        s.mem.swap_used = m.swap_used;
        s.mem.swap_total = m.swap_total;
    }
    s.bandwidth = pd.bandwidth;
    s.sensors = pd.sensors;
    s.fans = pd.fans;
    s

/// sysinfo-based data shared by every OS.
pub struct Common {
    sys: System,
    nets: Networks,
    disks: Disks,
    users: Users,
    net_counters: HashMap<String, (Counter, Counter)>,
}

impl Common {
    pub fn new() -> Self {
        let mut sys = System::new();
        sys.refresh_cpu_usage();
        Self {
            sys,
            nets: Networks::new_with_refreshed_list(),
            disks: Disks::new_with_refreshed_list(),
            users: Users::new_with_refreshed_list(),
            net_counters: HashMap::new(),
        }
    }

    pub fn sample(&mut self) -> Snapshot {
        let now = Instant::now();
        self.sys.refresh_cpu_usage();
        self.sys.refresh_memory();
        self.sys.refresh_processes(ProcessesToUpdate::All, true);
        self.nets.refresh(true);
        self.disks.refresh(true);

        let per_core: Vec<f64> = self.sys.cpus().iter().map(|c| c.cpu_usage() as f64 / 100.0).collect();
        let total = if per_core.is_empty() { 0.0 } else { per_core.iter().sum::<f64>() / per_core.len() as f64 };

        let mut ifaces = Vec::new();
        for (name, data) in self.nets.iter() {
            if name.starts_with("lo") || name.starts_with("utun") || name.starts_with("awdl") || name.starts_with("llw") {
                continue;
            }
            let (rc, tc) = self.net_counters.entry(name.clone()).or_default();
            let rx = rc.update(data.total_received(), now).unwrap_or(0.0);
            let tx = tc.update(data.total_transmitted(), now).unwrap_or(0.0);
            if data.total_received() > 0 || data.total_transmitted() > 0 {
                ifaces.push(NetIface { name: name.clone(), rx, tx });
            }
        }
        ifaces.sort_by(|a, b| (b.rx + b.tx).total_cmp(&(a.rx + a.tx)));
        let net = NetStats { rx: ifaces.iter().map(|i| i.rx).sum(), tx: ifaces.iter().map(|i| i.tx).sum(), ifaces };

        // The root filesystem (or the largest one) represents "Used".
        let disk = self
            .disks
            .iter()
            .find(|d| d.mount_point() == std::path::Path::new("/System/Volumes/Data"))
            .or_else(|| self.disks.iter().find(|d| d.mount_point() == std::path::Path::new("/")))
            .map(|d| DiskStats { used: d.total_space() - d.available_space(), total: d.total_space(), ..Default::default() })
            .unwrap_or_default();

        let procs = self
            .sys
            .processes()
            .values()
            .map(|p| ProcInfo {
                pid: p.pid().as_u32(),
                ppid: p.parent().map(|pp| pp.as_u32()),
                name: p.name().to_string_lossy().into_owned(),
                cmd: p.cmd().iter().map(|c| c.to_string_lossy()).collect::<Vec<_>>().join(" "),
                user: p
                    .user_id()
                    .and_then(|u| self.users.get_user_by_id(u))
                    .map(|u| u.name().to_string())
                    .unwrap_or_default(),
                cpu: p.cpu_usage(),
                mem: p.memory(),
                threads: p.tasks().map(|t| t.len()),
                start_time: p.start_time(),
            })
            .collect();

        let total_mem = self.sys.total_memory();
        let used_mem = self.sys.used_memory();
        Snapshot {
            host: HostInfo {
                chip: self.sys.cpus().first().map(|c| c.brand().trim().to_string()).unwrap_or_default(),
                os: System::long_os_version().unwrap_or_default(),
                hostname: System::host_name().unwrap_or_default(),
                cores_e: None,
                cores_p: None,
                cores_total: per_core.len(),
                uptime: std::time::Duration::from_secs(System::uptime()),
            },
            cpu: CpuStats { clusters: vec![], per_core, total },
            mem: MemStats {
                total: total_mem,
                used: used_mem,
                free: total_mem.saturating_sub(used_mem),
                swap_used: self.sys.used_swap(),
                swap_total: self.sys.total_swap(),
                ..Default::default()
            },
            net,
            disk,
            procs,
            ..Default::default()
        }
    }
}

impl Default for Common {
    fn default() -> Self {
        Self::new()
    }
}

/// Common + platform backend.
pub struct SystemCollector {
    common: Common,
    platform: Box<dyn Platform>,
    disk_r: Counter,
    disk_w: Counter,
}

impl SystemCollector {
    pub fn new(platform: Box<dyn Platform>) -> Self {
        Self { common: Common::new(), platform, disk_r: Counter::new(), disk_w: Counter::new() }
    }
}

impl Collector for SystemCollector {
    fn sample(&mut self) -> Snapshot {
        let now = Instant::now();
        let base = self.common.sample();
        self.platform.set_per_core(&base.cpu.per_core);
        let pd = self.platform.sample();
        let totals = pd.disk_totals;
        let mut s = merge(base, pd);
        if let Some((r, w)) = totals {
            s.disk.read = self.disk_r.update(r, now);
            s.disk.write = self.disk_w.update(w, now);
            s.disk.read_total = Some(r);
            s.disk.write_total = Some(w);
        }
        s.ai = ai::analyze(&s);
        s
    }
}
```

```rust
pub fn parse_cpu_list(s: &str) -> Vec<usize> {
    let mut out = Vec::new();
    for part in s.trim().split(',').filter(|p| !p.is_empty()) {
        match part.split_once('-') {
            Some((a, b)) => {
                if let (Ok(a), Ok(b)) = (a.parse::<usize>(), b.parse::<usize>()) {
                    out.extend(a..=b);
                }
            }
            None => {
                if let Ok(n) = part.parse() {
                    out.push(n);
                }
            }
        }
    }
    out
}
```

```rust
pub fn classify(name: &str) -> SensorKind {
    let n = name.to_lowercase();
    if ["coretemp", "k10temp", "zenpower", "cpu_thermal", "cpu"].iter().any(|p| n.starts_with(p)) {
        SensorKind::Cpu
    } else if ["amdgpu", "nouveau", "nvidia", "radeon", "i915", "xe"].iter().any(|p| n.starts_with(p)) {
        SensorKind::Gpu
    } else if n.starts_with("bat") {
        SensorKind::Battery
    } else if n.starts_with("nvme") || n.starts_with("drivetemp") {
        SensorKind::Disk
    } else {
        SensorKind::Other
    }
}

fn read_num(p: &Path) -> Option<f64> {
    std::fs::read_to_string(p).ok()?.trim().parse().ok()

pub fn read(root: &Path) -> (Vec<SensorGroup>, Vec<Fan>) {
    let mut groups: BTreeMap<SensorKind, Vec<(String, f64)>> = BTreeMap::new();
    let mut fans = Vec::new();
    let Ok(entries) = std::fs::read_dir(root.join("sys/class/hwmon")) else {
        return (Vec::new(), fans);
    };
    let mut dirs: Vec<_> = entries.flatten().map(|e| e.path()).collect();
    dirs.sort();
    for dir in dirs {
        let name = std::fs::read_to_string(dir.join("name")).map(|s| s.trim().to_string()).unwrap_or_default();
        let kind = classify(&name);
        let Ok(files) = std::fs::read_dir(&dir) else { continue };
        let mut files: Vec<String> = files.flatten().filter_map(|f| f.file_name().into_string().ok()).collect();
        files.sort();
        for f in files {
            if let Some(idx) = f.strip_prefix("temp").and_then(|r| r.strip_suffix("_input")) {
                let Some(milli) = read_num(&dir.join(&f)) else { continue };
                let c = milli / 1000.0;
                if !(-40.0..=150.0).contains(&c) {
                    continue;
                }
                let label = std::fs::read_to_string(dir.join(format!("temp{idx}_label")))
                    .map(|s| s.trim().to_string())
                    .unwrap_or_else(|_| format!("{name} temp{idx}"));
                groups.entry(kind).or_default().push((label, c));
            } else if let Some(idx) = f.strip_prefix("fan").and_then(|r| r.strip_suffix("_input")) {
                if let Some(rpm) = read_num(&dir.join(&f)) {
                    fans.push(Fan { label: format!("{name} fan{idx}"), rpm });
                }
            }
        }
    }
    let groups = groups.into_iter().map(|(kind, readings)| SensorGroup { kind, readings }).collect();
    (groups, fans)
}
```

```rust
    std::fs::read_to_string(p).ok()?.trim().parse().ok()

/// Energy consumed between two readings of a counter that wraps at `max`.
pub fn delta_uj(prev: u64, cur: u64, max: u64) -> u64 {
    if cur >= prev {
        cur - prev
    } else if max > prev {
        (max - prev) + cur
    } else {
        0
    }
}

/// Top-level zones (`intel-rapl:N`, not subzones) whose counter is readable by this user.
pub fn zones(root: &Path) -> Vec<Zone> {
    let Ok(entries) = std::fs::read_dir(root.join("sys/class/powercap")) else { return Vec::new() };
    let mut out: Vec<Zone> = entries
        .flatten()
        .filter_map(|e| {
            let fname = e.file_name().into_string().ok()?;
            let rest = fname.strip_prefix("intel-rapl:")?;
            if rest.contains(':') {
                return None;
            }
            let path = e.path();
            let name = std::fs::read_to_string(path.join("name")).ok()?.trim().to_string();
            let zone = Zone { name, max_uj: read_u64(&path.join("max_energy_range_uj")).unwrap_or(0), path };
            read_uj(&zone).map(|_| zone)
        })
        .collect();
    out.sort_by(|a, b| a.path.cmp(&b.path));
    out
}

pub fn read_uj(z: &Zone) -> Option<u64> {
    read_u64(&z.path.join("energy_uj"))
}
```

```rust
pub fn rapl_watts(prev: &mut Vec<(u64, Instant)>, zones: &[rapl::Zone], now: Instant) -> Option<PowerStats> {
    let cur: Vec<Option<u64>> = zones.iter().map(rapl::read_uj).collect();
    let mut out = PowerStats::default();
    let mut any = false;
    if prev.len() == zones.len() {
        for ((z, c), (pv, pt)) in zones.iter().zip(&cur).zip(prev.iter()) {
            let Some(c) = c else { continue };
            let dt = now.saturating_duration_since(*pt).as_secs_f64();
            if dt <= 0.0 {
                continue;
            }
            let w = rapl::delta_uj(*pv, *c, z.max_uj) as f64 / 1e6 / dt;
            let slot = if z.name.starts_with("package") {
                &mut out.cpu_w
            } else if z.name == "psys" {
                &mut out.system_w
            } else if z.name == "dram" {
                &mut out.dram_w
            } else {
                continue;
            };
            *slot = Some(slot.unwrap_or(0.0) + w);
            any = true;
        }
    }
    *prev = cur.into_iter().map(|c| (c.unwrap_or(0), now)).collect();
    any.then_some(out)
}

pub struct LinuxPlatform {
    root: PathBuf,
    hybrid: Option<(Vec<usize>, Vec<usize>)>,
    zones: Vec<rapl::Zone>,
    rapl_prev: Vec<(u64, Instant)>,
    per_core: Vec<f64>,
    #[cfg(target_os = "linux")]
    nvml: Option<super::nvml::NvmlGpu>,
}

impl LinuxPlatform {
    pub fn new(root: PathBuf) -> Self {
        let zones = rapl::zones(&root);
        if zones.is_empty() {
            crate::log::warn_once("rapl", "RAPL energy counters not readable; power shown as —");
        }
        Self {
            hybrid: topology::hybrid(&root),
            zones,
            rapl_prev: Vec::new(),
            per_core: Vec::new(),
            #[cfg(target_os = "linux")]
            nvml: super::nvml::NvmlGpu::new(),
            root,
        }
    }

    fn cluster(&self, kind: ClusterKind, cpus: &[usize]) -> CpuCluster {
        let usages: Vec<f64> = cpus.iter().filter_map(|i| self.per_core.get(*i).copied()).collect();
        let usage = if usages.is_empty() { 0.0 } else { usages.iter().sum::<f64>() / usages.len() as f64 };
        let freqs: Vec<u32> = cpus.iter().filter_map(|i| topology::cur_freq_mhz(&self.root, *i)).collect();
        let mhz = (!freqs.is_empty()).then(|| freqs.iter().sum::<u32>() / freqs.len() as u32);
        CpuCluster { kind, usage, mhz }
    }
}

impl Platform for LinuxPlatform {
    fn set_per_core(&mut self, per_core: &[f64]) {
        self.per_core = per_core.to_vec();
    }

    fn sample(&mut self) -> PlatformData {
        let now = Instant::now();
        let (sensors, fans) = hwmon::read(&self.root);
        let mut pd = PlatformData { sensors, fans, disk_totals: diskstats::totals(&self.root), ..Default::default() };
        match &self.hybrid {
            Some((p, e)) => {
                pd.cores_p = Some(p.len());
                pd.cores_e = Some(e.len());
                pd.clusters = vec![self.cluster(ClusterKind::Efficiency, e), self.cluster(ClusterKind::Performance, p)];
            }
            None => {
                let all: Vec<usize> = (0..self.per_core.len()).collect();
                if !all.is_empty() {
                    pd.clusters = vec![self.cluster(ClusterKind::All, &all)];
                }
            }
        }
        pd.power = rapl_watts(&mut self.rapl_prev, &self.zones, now);

        #[cfg(target_os = "linux")]
        if let Some(n) = &self.nvml {
            match n.read() {
                Ok((g, w)) => {
                    pd.gpu = Some(g);
                    if let Some(w) = w {
                        pd.power.get_or_insert_with(Default::default).gpu_w = Some(w);
                    }
                }
                Err(e) => crate::log::warn_once("nvml", &e),
            }
        }
        if pd.gpu.is_none()
            && let Some((g, w)) = amdgpu::read(&self.root)
        {
            pd.gpu = Some(g);
            if let Some(w) = w {
                pd.power.get_or_insert_with(Default::default).gpu_w = Some(w);
            }
        }
        pd
    }
}
```

```rust
/// Usage (0..1) and residency-weighted MHz from IOReport state residencies.
/// Active states map in order onto `freqs_mhz`; extra states reuse the last frequency.
pub fn residency_usage_mhz(states: &[(String, i64)], freqs_mhz: &[u32]) -> (f64, Option<u32>) {
    let total: i64 = states.iter().map(|s| s.1.max(0)).sum();
    if total <= 0 {
        return (0.0, None);
    }
    let active: Vec<i64> = states
        .iter()
        .filter(|(n, _)| !IDLE_STATES.contains(&n.as_str()))
        .map(|s| s.1.max(0))
        .collect();
    let active_sum: i64 = active.iter().sum();
    let usage = active_sum as f64 / total as f64;
    if active_sum == 0 || freqs_mhz.is_empty() {
        return (usage, None);
    }
    let weighted: f64 = active
        .iter()
        .enumerate()
        .map(|(i, r)| *r as f64 * freqs_mhz[i.min(freqs_mhz.len() - 1)] as f64)
        .sum();
    (usage, Some((weighted / active_sum as f64).round() as u32))
}

pub fn watts_from_energy(value: i64, unit: &str, dt_secs: f64) -> Option<f64> {
    if dt_secs <= 0.0 {
        return None;
    }
    let joules_per_unit = match unit.trim() {
        "mJ" => 1e-3,
        "uJ" | "µJ" => 1e-6,
        "nJ" => 1e-9,
        _ => return None,
    };
    Some(value.max(0) as f64 * joules_per_unit / dt_secs)
}

/// IORegistry `voltage-states*` blobs: pairs of LE u32 (freq, voltage).
pub fn parse_freq_table(data: &[u8]) -> Vec<u32> {
    let freqs: Vec<u64> = data
        .chunks_exact(8)
        .map(|c| u32::from_le_bytes([c[0], c[1], c[2], c[3]]) as u64)
        .filter(|f| *f > 0)
        .collect();
    let is_hz = freqs.iter().any(|f| *f > 10_000_000);
    freqs.into_iter().map(|f| if is_hz { (f / 1_000_000) as u32 } else { (f / 1_000) as u32 }).collect()
}

pub fn classify_smc_key(key: &str) -> Option<SensorKind> {
    let mut c = key.chars();
    if c.next()? != 'T' {
        return None;
    }
    Some(match c.next()? {
        'p' | 'e' | 'C' => SensorKind::Cpu,
        'g' | 'G' => SensorKind::Gpu,
        'B' => SensorKind::Battery,
        'H' => SensorKind::Disk,
        _ => SensorKind::Other,
    })
}

/// Activity Monitor style breakdown. `pressure_level` is `kern.memorystatus_level` (% free).
pub fn mem_detail(vm: &VmCounts, page_size: u64, total: u64, pressure_level: Option<u32>, swap: (u64, u64)) -> MemDetail {
    let app = vm.internal.saturating_sub(vm.purgeable) * page_size;
    let wired = vm.wired * page_size;
    let compressed = vm.compressor * page_size;
    let used = (app + wired + compressed).min(total);
    MemDetail {
        used,
        free: total - used,
        wired,
        active: vm.active * page_size,
        compressed,
        app,
        cached: (vm.external + vm.purgeable) * page_size,
        pressure: pressure_level.map(|l| (100u32.saturating_sub(l.min(100))) as f64 / 100.0),
        swap_used: swap.0,
        swap_total: swap.1,
    }
}

pub fn bandwidth_bucket(channel: &str) -> Bucket {
    let c = channel.to_uppercase();
    if c.contains("CPU") {
        Bucket::Cpu
    } else if c.starts_with("GFX") || c.starts_with("GPU") {
        Bucket::Gpu
    } else if c.starts_with("ANE") {
        Bucket::Ane
    } else if ["AVE", "VDEC", "VENC", "ISP", "MSR", "JPG", "PRORES", "MEDIA"].iter().any(|p| c.starts_with(p)) {
        Bucket::Media
    } else {
        Bucket::Other
    }
}
```

```rust
pub fn cfstr(s: &str) -> CFString {
    CFString::new(s)

/// Borrowed lookup (Get rule): the returned ref is owned by `dict`.
pub fn dict_get(dict: CFDictionaryRef, key: &str) -> Option<CFTypeRef> {
    if dict.is_null() {
        return None;
    }
    let k = cfstr(key);
    let mut out: *const std::ffi::c_void = std::ptr::null();
    let found = unsafe { CFDictionaryGetValueIfPresent(dict, k.as_concrete_TypeRef() as _, &mut out) };
    (found != 0 && !out.is_null()).then_some(out as CFTypeRef)
}

pub fn to_string(s: CFStringRef) -> Option<String> {
    if s.is_null() {
        return None;
    }
    Some(unsafe { CFString::wrap_under_get_rule(s) }.to_string())
}

pub fn to_i64(v: CFTypeRef) -> Option<i64> {
    if v.is_null() || unsafe { CFGetTypeID(v) } != unsafe { CFNumberGetTypeID() } {
        return None;
    }
    unsafe { CFNumber::wrap_under_get_rule(v as CFNumberRef) }.to_i64()
}

pub fn to_data(v: CFTypeRef) -> Option<Vec<u8>> {
    if v.is_null() || unsafe { CFGetTypeID(v) } != unsafe { CFDataGetTypeID() } {
        return None;
    }
    Some(unsafe { CFData::wrap_under_get_rule(v as CFDataRef) }.bytes().to_vec())
}

pub fn to_dict(v: CFTypeRef) -> Option<CFDictionaryRef> {
    (!v.is_null() && unsafe { CFGetTypeID(v) } == unsafe { CFDictionaryGetTypeID() }).then_some(v as CFDictionaryRef)
}

pub fn is_string(v: CFTypeRef) -> bool {
    !v.is_null() && unsafe { CFGetTypeID(v) } == unsafe { CFStringGetTypeID() }
}

/// Owned CF object released on drop (Create/Copy rule).
pub struct Owned(pub CFTypeRef);
impl Drop for Owned {
    fn drop(&mut self) {
        if !self.0.is_null() {
            unsafe { CFRelease(self.0) }
        }
    }
}
```

```rust
pub struct Service(pub IoObject);

impl Service {
    pub fn name(&self) -> Option<String> {
        let mut buf = [0 as c_char; 128];
        (unsafe { IORegistryEntryGetName(self.0, buf.as_mut_ptr()) } == 0)
            .then(|| unsafe { CStr::from_ptr(buf.as_ptr()) }.to_string_lossy().into_owned())
    }

    /// Returns an owned properties dictionary.
    pub fn properties(&self) -> Option<Owned> {
        let mut props: CFMutableDictionaryRef = std::ptr::null_mut();
        let kr = unsafe { IORegistryEntryCreateCFProperties(self.0, &mut props, kCFAllocatorDefault, 0) };
        (kr == 0 && !props.is_null()).then(|| Owned(props as CFTypeRef))
    }
}

pub fn services(class: &str) -> Vec<Service> {
    let Ok(c) = CString::new(class) else { return Vec::new() };
    let mut it: IoObject = 0;
    // IOServiceGetMatchingServices consumes the matching dictionary.
    let kr = unsafe { IOServiceGetMatchingServices(kIOMainPortDefault, IOServiceMatching(c.as_ptr()), &mut it) };
    if kr != 0 {
        return Vec::new();
    }
    let mut out = Vec::new();
    loop {
        let o = unsafe { IOIteratorNext(it) };
        if o == 0 {
            break;
        }
        out.push(Service(o));
    }
    unsafe { IOObjectRelease(it) };
    out
}
```

```rust
const GROUPS: [(&str, Option<&str>); 5] = [
    ("Energy Model", None),
    ("CPU Stats", Some("CPU Core Performance States")),
    ("GPU Stats", Some("GPU Performance States")),
    ("AMC Stats", None),

pub struct IoSample {

    pub gpu_usage: Option<f64>,
    pub gpu_mhz: Option<u32>,
    pub power: PowerStats,

pub struct IoReport {
    sub: Subscription,
    subbed: CFMutableDictionaryRef,
    _channels: Owned,
    prev: Option<(Owned, Instant)>,
    dvfs: DvfsTables,
}

// The subscription is only touched from the collector thread.
unsafe impl Send for IoReport {}

impl IoReport {
    pub fn new() -> anyhow::Result<Self> {
        let mut merged: Option<CFDictionaryRef> = None;
        let mut owned = Vec::new();
        for (g, sg) in GROUPS {
            let gs = cf::cfstr(g);
            let sgs = sg.map(cf::cfstr);
            let ch = unsafe {
                IOReportCopyChannelsInGroup(
                    gs.as_concrete_TypeRef(),
                    sgs.as_ref().map(|s| s.as_concrete_TypeRef()).unwrap_or(std::ptr::null()),
                    0,
                    0,
                    0,
                )
            };
            if ch.is_null() {
                crate::log::warn_once(&format!("ioreport-{g}"), "channel group not present");
                continue;
            }
            match merged {
                None => merged = Some(ch),
                Some(m) => unsafe { IOReportMergeChannels(m, ch, std::ptr::null()) },
            }
            owned.push(Owned(ch as CFTypeRef));
        }
        let merged = merged.context("no IOReport channel groups available")?;
        let channels = unsafe { CFDictionaryCreateMutableCopy(kCFAllocatorDefault, CFDictionaryGetCount(merged), merged) };
        drop(owned);
        let mut subbed: CFMutableDictionaryRef = std::ptr::null_mut();
        let sub = unsafe { IOReportCreateSubscription(std::ptr::null(), channels, &mut subbed, 0, std::ptr::null()) };
        if sub.is_null() {
            bail!("IOReportCreateSubscription failed");
        }
        Ok(Self { sub, subbed, _channels: Owned(channels as CFTypeRef), prev: None, dvfs: iokit::dvfs_tables() })
    }

    fn raw(&self) -> Owned {
        Owned(unsafe { IOReportCreateSamples(self.sub, self.subbed, std::ptr::null()) } as CFTypeRef)
    }

    pub fn sample(&mut self) -> anyhow::Result<IoSample> {
        let now = Instant::now();
        let cur = self.raw();
        if cur.0.is_null() {
            bail!("IOReportCreateSamples returned null");
        }
        let Some((prev, pt)) = self.prev.replace((cur, now)) else {
            return Ok(IoSample::default());
        };
        let cur = &self.prev.as_ref().unwrap().0;
        let dt = now.saturating_duration_since(pt).as_secs_f64();
        let delta = Owned(unsafe { IOReportCreateSamplesDelta(prev.0 as _, cur.0 as _, std::ptr::null()) } as CFTypeRef);
        if delta.0.is_null() {
            bail!("IOReportCreateSamplesDelta returned null");
        }
        Ok(self.parse(delta.0 as CFDictionaryRef, dt))
    }

    fn parse(&self, delta: CFDictionaryRef, dt: f64) -> IoSample {
        let mut out = IoSample::default();
        let mut e_states: Vec<Vec<(String, i64)>> = Vec::new();
        let mut p_states: Vec<Vec<(String, i64)>> = Vec::new();
        let mut bw = Bandwidth::default();
        let mut bw_any = false;
        let Some(arr) = cf::dict_get(delta, "IOReportChannels") else { return out };
        let arr = arr as CFArrayRef;
        for i in 0..unsafe { CFArrayGetCount(arr) } {
            let ch = unsafe { CFArrayGetValueAtIndex(arr, i) } as CFDictionaryRef;
            let group = cf::to_string(unsafe { IOReportChannelGetGroup(ch) }).unwrap_or_default();
            let sub = cf::to_string(unsafe { IOReportChannelGetSubGroup(ch) }).unwrap_or_default();
            let name = cf::to_string(unsafe { IOReportChannelGetChannelName(ch) }).unwrap_or_default();
            let unit = cf::to_string(unsafe { IOReportChannelGetUnitLabel(ch) }).unwrap_or_default();
            let states = || -> Vec<(String, i64)> {
                (0..unsafe { IOReportStateGetCount(ch) })
                    .map(|j| {
                        (
                            cf::to_string(unsafe { IOReportStateGetNameForIndex(ch, j) }).unwrap_or_default(),
                            unsafe { IOReportStateGetResidency(ch, j) },
                        )
                    })
                    .collect()
            };
            match group.as_str() {
                "Energy Model" => {
                    let w = calc::watts_from_energy(unsafe { IOReportSimpleGetIntegerValue(ch, 0) }, &unit, dt);
                    let slot = if name == "GPU Energy" {
                        &mut out.power.gpu_w
                    } else if name.ends_with("CPU Energy") {
                        &mut out.power.cpu_w
                    } else if name.starts_with("ANE") {
                        &mut out.power.ane_w
                    } else if name.starts_with("DRAM") {
                        &mut out.power.dram_w
                    } else {
                        continue;
                    };
                    if let Some(w) = w {
                        *slot = Some(slot.unwrap_or(0.0) + w);
                    }
                }
                "CPU Stats" if sub == "CPU Core Performance States" => {
                    if name.starts_with("ECPU") {
                        e_states.push(states());
                    } else if name.starts_with("PCPU") {
                        p_states.push(states());
                    }
                }
                "GPU Stats" if sub == "GPU Performance States" && name == "GPUPH" => {
                    let (u, mhz) = calc::residency_usage_mhz(&states(), &self.dvfs.gpu);
                    out.gpu_usage = Some(u);
                    out.gpu_mhz = mhz;
                }
                "AMC Stats" | "PMP" if unit.trim() == "B" || unit.trim() == "bytes" => {
                    let bytes = unsafe { IOReportSimpleGetIntegerValue(ch, 0) }.max(0) as f64 / dt.max(1e-9);
                    bw_any = true;
                    bw.total += bytes;
                    match calc::bandwidth_bucket(&name) {
                        Bucket::Cpu => bw.cpu += bytes,
                        Bucket::Gpu => bw.gpu += bytes,
                        Bucket::Media => bw.media += bytes,
                        Bucket::Ane => bw.ane += bytes,
                        Bucket::Other => bw.other += bytes,
                    }
                }
                _ => {}
            }
        }
        for (kind, cores, table) in [
            (ClusterKind::Efficiency, &e_states, &self.dvfs.ecpu),
            (ClusterKind::Performance, &p_states, &self.dvfs.pcpu),
        ] {
            if cores.is_empty() {
                continue;
            }
            let per: Vec<(f64, Option<u32>)> = cores.iter().map(|s| calc::residency_usage_mhz(s, table)).collect();
            let usage = per.iter().map(|p| p.0).sum::<f64>() / per.len() as f64;
            let mhz = per.iter().filter_map(|p| p.1).max();
            out.clusters.push(CpuCluster { kind, usage, mhz });
        }
        let sys: f64 = [out.power.cpu_w, out.power.gpu_w, out.power.ane_w, out.power.dram_w].iter().flatten().sum();
        out.power.system_w = (sys > 0.0).then_some(sys);
        out.bandwidth = bw_any.then_some(bw);
        out
    }

    /// Dumps every channel (group/subgroup/name/unit) to the log; used to tune bandwidth mapping.
    pub fn log_channels(&self) {
        let raw = self.raw();
        let Some(arr) = cf::dict_get(raw.0 as CFDictionaryRef, "IOReportChannels") else { return };
        let arr = arr as CFArrayRef;
        for i in 0..unsafe { CFArrayGetCount(arr) } {
            let ch = unsafe { CFArrayGetValueAtIndex(arr, i) } as CFDictionaryRef;
            crate::log::info(&format!(
                "ioreport channel: {} / {} / {} [{}]",
                cf::to_string(unsafe { IOReportChannelGetGroup(ch) }).unwrap_or_default(),
                cf::to_string(unsafe { IOReportChannelGetSubGroup(ch) }).unwrap_or_default(),
                cf::to_string(unsafe { IOReportChannelGetChannelName(ch) }).unwrap_or_default(),
                cf::to_string(unsafe { IOReportChannelGetUnitLabel(ch) }).unwrap_or_default(),
            ));
        }
    }
}
```

```rust
use std::ffi::CString;

use super::calc::VmCounts;

pub fn sysctl_raw(name: &str) -> Option<Vec<u8>> {
    let c = CString::new(name).ok()?;
    let mut len: libc::size_t = 0;
    if unsafe { libc::sysctlbyname(c.as_ptr(), std::ptr::null_mut(), &mut len, std::ptr::null_mut(), 0) } != 0 {
        return None;
    }
    let mut buf = vec![0u8; len];
    if unsafe { libc::sysctlbyname(c.as_ptr(), buf.as_mut_ptr() as *mut _, &mut len, std::ptr::null_mut(), 0) } != 0 {
        return None;
    }
    buf.truncate(len);
    Some(buf)
}

pub fn sysctl_string(name: &str) -> Option<String> {
    let b = sysctl_raw(name)?;
    Some(String::from_utf8_lossy(&b).trim_end_matches('\0').trim().to_string())
}

pub fn sysctl_u32(name: &str) -> Option<u32> {
    let b = sysctl_raw(name)?;
    Some(u32::from_ne_bytes(b.get(..4)?.try_into().ok()?))
}

pub fn sysctl_u64(name: &str) -> Option<u64> {
    let b = sysctl_raw(name)?;
    match b.len() {
        8 => Some(u64::from_ne_bytes(b.try_into().ok()?)),
        4 => Some(u32::from_ne_bytes(b.try_into().ok()?) as u64),
        _ => None,
    }
}

pub fn swap() -> Option<(u64, u64)> {
    let b = sysctl_raw("vm.swapusage")?;

    let used = u64::from_ne_bytes(b.get(16..24)?.try_into().ok()?);
    Some((used, total))
}
```

```rust
use std::collections::BTreeMap;

use anyhow::bail;

use super::calc;
use super::iokit::{self, IOConnectCallStructMethod, IOServiceClose, IOServiceOpen, IoObject, mach_task_self_};
use crate::model::{Fan, SensorGroup, SensorKind};

#[repr(C)]
#[derive(Default, Clone, Copy)]
struct KeyDataVer {
    major: u8,
    minor: u8,
    build: u8,
    reserved: u8,
    release: u16,
}

#[repr(C)]
#[derive(Default, Clone, Copy)]
struct PLimitData {
    version: u16,
    length: u16,
    cpu_p_limit: u32,
    gpu_p_limit: u32,
    mem_p_limit: u32,
}

#[repr(C)]
#[derive(Default, Clone, Copy)]
struct KeyInfo {
    data_size: u32,
    data_type: u32,
    data_attributes: u8,
}

#[repr(C)]
#[derive(Default, Clone, Copy)]
struct KeyData {
    key: u32,
    vers: KeyDataVer,
    p_limit_data: PLimitData,
    key_info: KeyInfo,
    result: u8,
    status: u8,
    data8: u8,
    data32: u32,
    bytes: [u8; 32],
}

const CMD_READ_BYTES: u8 = 5;
const CMD_READ_INDEX: u8 = 8;
const CMD_READ_KEYINFO: u8 = 9;
const KERNEL_INDEX_SMC: u32 = 2;

fn fourcc(s: &str) -> u32 {
    s.bytes().fold(0u32, |acc, b| (acc << 8) | b as u32)
}

fn fourcc_str(v: u32) -> String {
    String::from_utf8_lossy(&v.to_be_bytes()).into_owned()
}

pub struct Smc {
    conn: IoObject,
    temp_keys: Vec<(String, SensorKind)>,
    fan_count: u8,
}

unsafe impl Send for Smc {}

impl Drop for Smc {
    fn drop(&mut self) {
        unsafe { IOServiceClose(self.conn) };
    }
}

impl Smc {
    pub fn open() -> anyhow::Result<Self> {
        let svc = iokit::services("AppleSMC").into_iter().next();
        let Some(svc) = svc else { bail!("AppleSMC service not found") };
        let mut conn: IoObject = 0;
        let kr = unsafe { IOServiceOpen(svc.0, mach_task_self_, 0, &mut conn) };
        if kr != 0 {
            bail!("IOServiceOpen(AppleSMC) failed: {kr}");
        }
        let mut smc = Self { conn, temp_keys: Vec::new(), fan_count: 0 };
        smc.discover();
        Ok(smc)
    }

    fn call(&self, input: &KeyData) -> Option<KeyData> {
        let mut out = KeyData::default();
        let mut size = std::mem::size_of::<KeyData>();
        let kr = unsafe {
            IOConnectCallStructMethod(
                self.conn,
                KERNEL_INDEX_SMC,
                input as *const _ as *const _,
                std::mem::size_of::<KeyData>(),
                &mut out as *mut _ as *mut _,
                &mut size,
            )
        };
        (kr == 0 && out.result == 0).then_some(out)
    }

    fn key_info(&self, key: u32) -> Option<KeyInfo> {
        self.call(&KeyData { key, data8: CMD_READ_KEYINFO, ..Default::default() }).map(|o| o.key_info)
    }

    fn read(&self, key: &str) -> Option<(KeyInfo, [u8; 32])> {
        let k = fourcc(key);
        let info = self.key_info(k)?;
        let out = self.call(&KeyData { key: k, key_info: info, data8: CMD_READ_BYTES, ..Default::default() })?;
        Some((info, out.bytes))
    }

    fn read_f32(&self, key: &str) -> Option<f32> {
        let (info, b) = self.read(key)?;
        (info.data_type == fourcc("flt ") && info.data_size == 4).then(|| f32::from_le_bytes([b[0], b[1], b[2], b[3]]))
    }

    fn discover(&mut self) {
        let count = self.read("#KEY").map(|(_, b)| u32::from_be_bytes([b[0], b[1], b[2], b[3]])).unwrap_or(0);
        for i in 0..count {
            let Some(out) = self.call(&KeyData { data8: CMD_READ_INDEX, data32: i, ..Default::default() }) else { continue };
            let name = fourcc_str(out.key);
            let Some(kind) = calc::classify_smc_key(&name) else { continue };
            if let Some(v) = self.read_f32(&name)
                && (5.0..=130.0).contains(&v)
            {
                self.temp_keys.push((name, kind));
            }
        }
        self.fan_count = self.read("FNum").map(|(_, b)| b[0]).unwrap_or(0);
    }

    pub fn temperatures(&mut self) -> Vec<SensorGroup> {
        let mut groups: BTreeMap<SensorKind, Vec<(String, f64)>> = BTreeMap::new();
        for (key, kind) in &self.temp_keys {
            if let Some(v) = self.read_f32(key)
                && (5.0..=130.0).contains(&v)
            {
                groups.entry(*kind).or_default().push((key.clone(), v as f64));
            }
        }
        groups.into_iter().map(|(kind, readings)| SensorGroup { kind, readings }).collect()
    }

    pub fn fans(&mut self) -> Vec<Fan> {
        (0..self.fan_count)
            .filter_map(|i| self.read_f32(&format!("F{i}Ac")).map(|rpm| Fan { label: format!("Fan {i}"), rpm: rpm as f64 }))
            .collect()
    }
}
```

```rust
const UNITS: [&str; 5] = ["B", "KB", "MB", "GB", "TB"];

fn scaled(v: f64) -> (f64, &'static str) {
    let mut v = v;
    let mut i = 0;
    while v >= 1024.0 && i < UNITS.len() - 1 {
        v /= 1024.0;
        i += 1;
    }
    (v, UNITS[i])
}

pub fn bytes(b: u64) -> String {
    let (v, u) = scaled(b as f64);
    match u {
        "B" | "KB" | "MB" => format!("{v:.0} {u}"),
        "GB" => format!("{v:.1} {u}"),
        _ => format!("{v:.2} {u}"),
    }
}

pub fn rate(bps: f64) -> String {
    if !bps.is_finite() {
        return dash().into();
    }
    // network/disk/bandwidth rates use decimal units like the screenshot
    let mut v = bps.max(0.0);
    let mut i = 0;
    while v >= 1000.0 && i < UNITS.len() - 1 {
        v /= 1000.0;
        i += 1;
    }
    format!("{v:.0} {}/s", UNITS[i])
}

pub fn pct(r: f64) -> String {
    format!("{:.0}%", (r * 100.0).max(0.0))
}

pub fn mhz(m: Option<u32>) -> String {
    m.map(|m| format!("{m} MHz")).unwrap_or_else(|| dash().into())
}

pub fn watts(w: Option<f64>) -> String {
    w.map(|w| format!("{w:.1} W")).unwrap_or_else(|| dash().into())
}

pub fn temp(c: f64) -> String {
    format!("{c:.0}°C")
}

pub fn uptime(d: Duration) -> String {
    let s = d.as_secs();
    let (days, h, m) = (s / 86_400, (s % 86_400) / 3600, (s % 3600) / 60);
    if days > 0 { format!("{days}d {h}h") } else { format!("{h}h {m}m") }
}

/// 35431 → "35.431" (thousands separator like the screenshot's PID column)
pub fn thousands(n: u32) -> String {
    let s = n.to_string();
    let mut out = String::new();
    for (i, c) in s.chars().enumerate() {
        if i > 0 && (s.len() - i) % 3 == 0 {
            out.push('.');
        }
        out.push(c);
    }
    out
}

/// Truncates to `width` display columns (CJK = 2), adding `…` when cut.
pub fn truncate(s: &str, width: usize) -> String {
    use unicode_width::UnicodeWidthChar;
    let total: usize = s.chars().map(|c| c.width().unwrap_or(0)).sum();
    if total <= width {
        return s.to_string();
    }
    if width == 0 {
        return String::new();
    }
    let mut out = String::new();
    let mut w = 0;
    for c in s.chars() {
        let cw = c.width().unwrap_or(0);
        if w + cw > width - 1 {
            break;
        }
        out.push(c);
        w += cw;
    }
    out.push('…');
    out
}
```

```rust
use ratatui::buffer::Buffer;
use ratatui::layout::Rect;
use ratatui::style::{Color, Modifier, Style};
use ratatui::symbols::Marker;
use ratatui::text::{Line, Span};
use ratatui::widgets::{Axis, Block, BorderType, Borders, Chart, Dataset, GraphType, Widget};
// `Chart` is constructed inside `render_history`.

use super::theme::Theme;

/// Two rows: `label ........ value` and a thin bar filled to `ratio`.
pub struct LabeledBar<'a> {
    pub label: &'a str,
    pub value: String,
    pub ratio: f64,
    pub color: Color,
    pub theme: &'a Theme,
}

impl Widget for LabeledBar<'_> {
    fn render(self, area: Rect, buf: &mut Buffer) {
        if area.height == 0 || area.width == 0 {
            return;
        }
        let w = area.width as usize;
        let value_w = unicode_width::UnicodeWidthStr::width(self.value.as_str());
        let label = super::fmt::truncate(self.label, w.saturating_sub(value_w + 1));
        buf.set_string(area.x, area.y, &label, Style::default().fg(self.theme.dim));
        let vx = area.x + (w.saturating_sub(value_w)) as u16;
        buf.set_string(vx, area.y, &self.value, Style::default().fg(self.theme.fg).add_modifier(Modifier::BOLD));
        if area.height < 2 {
            return;
        }
        let filled = ((self.ratio.clamp(0.0, 1.0) * w as f64).round() as usize).min(w);
        for i in 0..w {
            let color = if i < filled { self.color } else { self.theme.bar_bg };
            buf.set_string(area.x + i as u16, area.y + 1, "━", Style::default().fg(color));
        }
    }
}

pub fn panel_block(title: &str, idx: Option<usize>, focused: bool, theme: &Theme) -> Block<'static> {
    let mut spans = Vec::new();
    if let Some(i) = idx {
        spans.push(Span::styled(format!("[{i}] "), Style::default().fg(if focused { theme.accent } else { theme.dim })));
    }
    spans.push(Span::styled(title.to_uppercase(), Style::default().fg(theme.dim).add_modifier(Modifier::BOLD)));
    Block::default()
        .borders(Borders::ALL)
        .border_type(BorderType::Rounded)
        .border_style(Style::default().fg(if focused { theme.border_focus } else { theme.border }))
        .title(Line::from(spans))
        .style(Style::default().bg(theme.bg).fg(theme.fg))
}

/// Renders a braille history chart for `series` into `area`.
pub fn render_history(frame: &mut ratatui::Frame, area: Rect, series: &[(Vec<(f64, f64)>, Color)], x_len: f64, y_max: f64) {
    if area.height == 0 || area.width == 0 {
        return;
    }
    let datasets: Vec<Dataset> = series
        .iter()
        .map(|(pts, color)| {
            Dataset::default().marker(Marker::Braille).graph_type(GraphType::Line).style(Style::default().fg(*color)).data(pts)
        })
        .collect();
    let chart = Chart::new(datasets)
        .x_axis(Axis::default().bounds([0.0, x_len.max(1.0)]))
        .y_axis(Axis::default().bounds([0.0, y_max.max(f64::EPSILON)]));
    frame.render_widget(chart, area);
}
```

```rust
fn cmp(a: &ProcInfo, b: &ProcInfo, sort: SortKey) -> std::cmp::Ordering {
    match sort {
        SortKey::Cpu => b.cpu.total_cmp(&a.cpu).then(a.pid.cmp(&b.pid)),
        SortKey::Mem => b.mem.cmp(&a.mem).then(a.pid.cmp(&b.pid)),
        SortKey::Pid => a.pid.cmp(&b.pid),
        SortKey::Name => a.name.to_lowercase().cmp(&b.name.to_lowercase()).then(a.pid.cmp(&b.pid)),
    }
}

pub fn arrange(procs: &[ProcInfo], filter: &str, sort: SortKey, reverse: bool, tree: bool) -> Vec<Row> {
    let f = filter.to_lowercase();
    let mut idx: Vec<usize> = (0..procs.len()).filter(|i| f.is_empty() || procs[*i].name.to_lowercase().contains(&f)).collect();
    let order = |a: &usize, b: &usize| {
        let o = cmp(&procs[*a], &procs[*b], sort);
        if reverse { o.reverse() } else { o }
    };
    idx.sort_by(order);
    if !tree || !f.is_empty() {
        return idx.into_iter().map(|i| Row { idx: i, depth: 0 }).collect();
    }
    let by_pid: HashMap<u32, usize> = idx.iter().map(|i| (procs[*i].pid, *i)).collect();
    let mut children: HashMap<u32, Vec<usize>> = HashMap::new();
    let mut roots = Vec::new();
    for i in &idx {
        match procs[*i].ppid.filter(|pp| by_pid.contains_key(pp) && *pp != procs[*i].pid) {
            Some(pp) => children.entry(pp).or_default().push(*i),
            None => roots.push(*i),
        }
    }
    let mut out = Vec::with_capacity(idx.len());
    let mut stack: Vec<(usize, usize)> = roots.into_iter().rev().map(|i| (i, 0)).collect();
    let mut seen = std::collections::HashSet::new();
    while let Some((i, d)) = stack.pop() {
        if !seen.insert(i) {
            continue; // cycle guard
        }
        out.push(Row { idx: i, depth: d });
        if let Some(ch) = children.get(&procs[i].pid) {
            for c in ch.iter().rev() {
                stack.push((*c, d + 1));
            }
        }
    }
    out
}

#[derive(Debug, Clone, Default)]
pub struct ProcView {
    pub filter: String,
    pub sort: SortKey,
    pub reverse: bool,
    pub tree: bool,
    pub selected_pid: Option<u32>,
    pub cursor: usize,
    pub offset: usize,
}

impl ProcView {
    pub fn from_cfg(c: &ProcCfg) -> Self {
        Self { sort: c.sort, reverse: c.reverse, tree: c.tree, ..Default::default() }
    }

    /// Re-anchors the cursor on `selected_pid` after the rows changed; clamps otherwise.
    pub fn sync(&mut self, rows: &[Row], procs: &[ProcInfo]) {
        if let Some(pid) = self.selected_pid
            && let Some(pos) = rows.iter().position(|r| procs[r.idx].pid == pid)
        {
            self.cursor = pos;
            return;
        }
        self.cursor = self.cursor.min(rows.len().saturating_sub(1));
        self.selected_pid = rows.get(self.cursor).map(|r| procs[r.idx].pid);
    }

    pub fn move_by(&mut self, delta: isize, rows: &[Row], procs: &[ProcInfo]) {
        if rows.is_empty() {
            self.cursor = 0;
            self.selected_pid = None;
            return;
        }
        let max = rows.len() as isize - 1;
        self.cursor = (self.cursor as isize + delta).clamp(0, max) as usize;
        self.selected_pid = Some(procs[rows[self.cursor].idx].pid);
    }

    pub fn top(&mut self, rows: &[Row], procs: &[ProcInfo]) {
        self.move_by(-(rows.len() as isize), rows, procs);
    }

    pub fn bottom(&mut self, rows: &[Row], procs: &[ProcInfo]) {
        self.move_by(rows.len() as isize, rows, procs);
    }

    pub fn selected<'a>(&self, rows: &[Row], procs: &'a [ProcInfo]) -> Option<&'a ProcInfo> {
        rows.get(self.cursor).map(|r| &procs[r.idx])
    }
}

pub fn errno_message(errno: i32, pid: u32) -> String {
    match errno {
        libc::ESRCH => format!("no such process: {pid}"),
        libc::EPERM => format!("permission denied: {pid}"),
        e => format!("kill {pid} failed: errno {e}"),
    }
}

pub fn send_signal(pid: u32, sig: Sig) -> Result<(), String> {
    let s = match sig {
        Sig::Term => libc::SIGTERM,
        Sig::Kill => libc::SIGKILL,
    };
    let Ok(p) = i32::try_from(pid) else { return Err(errno_message(libc::ESRCH, pid)) };
    if p <= 0 {
        return Err(errno_message(libc::ESRCH, pid));
    }
    if unsafe { libc::kill(p, s) } == 0 {
        Ok(())
    } else {
        Err(errno_message(std::io::Error::last_os_error().raw_os_error().unwrap_or(0), pid))
    }
}
```

```rust
impl App {
    pub fn new(cfg: Config, theme: Theme, ctl: Option<Sender<Control>>, killer: Killer) -> App {
        App {
            procs: ProcView::from_cfg(&cfg.processes),
            interval_ms: cfg.interval_ms,
            cfg,
            theme,
            snap: None,
            hist: History::new(300),
            focus: PanelId::Processes,
            zoomed: false,
            details: false,
            mode: Mode::Normal,
            sensors: SensorView::default(),
            status: None,
            paused: false,
            quit: false,
            notices: Vec::new(),
            ctl,
            killer,
        }
    }

    pub fn set_status(&mut self, msg: impl Into<String>) {
        self.status = Some((msg.into(), Instant::now()));
    }

    pub fn status_text(&self) -> Option<&str> {
        self.status.as_ref().filter(|(_, t)| t.elapsed() < STATUS_TTL).map(|(m, _)| m.as_str())
    }

    pub fn on_snapshot(&mut self, s: Snapshot) {
        self.hist.push(&s);
        self.notices = notices_for(&s);
        self.snap = Some(s);
        if !self.visible().contains(&self.focus) {
            self.focus = PanelId::Processes;
        }
    }

    pub fn visible(&self) -> Vec<PanelId> {
        PanelId::ALL
            .into_iter()
            .filter(|p| !self.cfg.panels.hidden.iter().any(|h| h == p.config_name()))
            .filter(|p| {
                let Some(s) = &self.snap else { return true };
                if !self.cfg.panels.hide_empty {
                    return true;
                }
                match p {
                    PanelId::Gpu => gpu_has_data(s),
                    PanelId::Sensors => sensors_have_data(s),
                    _ => true,
                }
            })
            .collect()
    }

    fn send(&self, c: Control) {
        if let Some(tx) = &self.ctl {
            let _ = tx.send(c);
        }
    }

    fn cycle_focus(&mut self, forward: bool) {
        let v = self.visible();
        let Some(pos) = v.iter().position(|p| *p == self.focus) else {
            self.focus = v.first().copied().unwrap_or(PanelId::Processes);
            return;
        };
        let n = v.len();
        self.focus = v[if forward { (pos + 1) % n } else { (pos + n - 1) % n }];
    }

    fn set_interval(&mut self, ms: u64) {
        self.interval_ms = config::clamp_interval(ms);
        self.send(Control::SetInterval(Duration::from_millis(self.interval_ms)));
        self.set_status(format!("refresh every {} ms", self.interval_ms));
    }

    fn proc_rows(&self) -> (Vec<super::process::Row>, Vec<crate::model::ProcInfo>) {
        let procs = self.snap.as_ref().map(|s| s.procs.clone()).unwrap_or_default();
        let rows = arrange(&procs, &self.procs.filter, self.procs.sort, self.procs.reverse, self.procs.tree);
        (rows, procs)
    }

    pub fn on_key(&mut self, k: KeyEvent) {
        if k.modifiers.contains(KeyModifiers::CONTROL) && k.code == KeyCode::Char('c') {
            self.quit = true;
            return;
        }
        match self.mode.clone() {
            Mode::Help => {
                if matches!(k.code, KeyCode::Char('?') | KeyCode::Esc | KeyCode::Char('q')) {
                    self.mode = Mode::Normal;
                }
            }
            Mode::Filter => match k.code {
                KeyCode::Esc => {
                    self.procs.filter.clear();
                    self.mode = Mode::Normal;
                }
                KeyCode::Enter => self.mode = Mode::Normal,
                KeyCode::Backspace => {
                    self.procs.filter.pop();
                }
                KeyCode::Char(c) => self.procs.filter.push(c),
                _ => {}
            },
            Mode::Confirm(pid, name, sig) => {
                if matches!(k.code, KeyCode::Char('y') | KeyCode::Char('Y') | KeyCode::Enter) {
                    let label = if sig == Sig::Kill { "SIGKILL" } else { "SIGTERM" };
                    match (self.killer)(pid, sig) {
                        Ok(()) => self.set_status(format!("{label} sent to {pid} ({name})")),
                        Err(e) => self.set_status(e),
                    }
                }
                self.mode = Mode::Normal;
            }
            Mode::Normal => self.on_key_normal(k),
        }
    }

    fn on_key_normal(&mut self, k: KeyEvent) {
        match k.code {
            KeyCode::Char('q') => self.quit = true,
            KeyCode::Char('?') => self.mode = Mode::Help,
            KeyCode::Tab => self.cycle_focus(true),
            KeyCode::BackTab => self.cycle_focus(false),
            KeyCode::Char(c @ '1'..='8') => {
                if let Some(p) = PanelId::from_number(c as usize - '0' as usize)
                    && self.visible().contains(&p)
                {
                    self.focus = p;
                }
            }
            KeyCode::Char('z') => self.zoomed = !self.zoomed,
            KeyCode::Enter if self.focus == PanelId::Processes && self.zoomed => self.details = !self.details,
            KeyCode::Enter => self.zoomed = !self.zoomed,
            KeyCode::Esc => {
                if self.details {
                    self.details = false;
                } else if self.zoomed {
                    self.zoomed = false;
                } else {
                    self.procs.filter.clear();
                }
            }
            KeyCode::Char('p') => {
                self.paused = !self.paused;
                self.send(Control::Pause(self.paused));
            }
            KeyCode::Char('+') | KeyCode::Char('=') => self.set_interval(self.interval_ms / 2),
            KeyCode::Char('-') => self.set_interval(self.interval_ms * 2),
            _ => match self.focus {
                PanelId::Processes => self.on_key_procs(k),
                PanelId::Sensors => self.on_key_sensors(k),
                _ => {}
            },
        }
    }

    fn on_key_procs(&mut self, k: KeyEvent) {
        let (rows, procs) = self.proc_rows();
        self.procs.sync(&rows, &procs);
        let page = 10;
        match k.code {
            KeyCode::Up => self.procs.move_by(-1, &rows, &procs),
            KeyCode::Down | KeyCode::Char('j') => self.procs.move_by(1, &rows, &procs),
            KeyCode::PageUp => self.procs.move_by(-page, &rows, &procs),
            KeyCode::PageDown => self.procs.move_by(page, &rows, &procs),
            KeyCode::Char('g') => self.procs.top(&rows, &procs),
            KeyCode::Char('G') => self.procs.bottom(&rows, &procs),
            KeyCode::Char('/') => self.mode = Mode::Filter,
            KeyCode::Char('s') => self.procs.sort = self.procs.sort.next(),
            KeyCode::Char('S') => self.procs.reverse = !self.procs.reverse,
            KeyCode::Char('t') => self.procs.tree = !self.procs.tree,
            KeyCode::Char(c @ ('k' | 'K')) => {
                if let Some(p) = self.procs.selected(&rows, &procs) {
                    let sig = if c == 'K' { Sig::Kill } else { Sig::Term };
                    self.mode = Mode::Confirm(p.pid, p.name.clone(), sig);
                }
            }
            _ => {}
        }
    }

    fn on_key_sensors(&mut self, k: KeyEvent) {
        let groups: Vec<_> = self.snap.as_ref().map(|s| s.sensors.iter().map(|g| g.kind).collect()).unwrap_or_default();
        if groups.is_empty() {
            return;
        }
        let sel = &mut self.sensors.selected;
        match k.code {
            KeyCode::Up => *sel = sel.saturating_sub(1),
            KeyCode::Down => *sel = (*sel + 1).min(groups.len() - 1),
            KeyCode::Char(' ') => {
                let kind = groups[(*sel).min(groups.len() - 1)];
                if !self.sensors.expanded.remove(&kind) {
                    self.sensors.expanded.insert(kind);
                }
            }
            _ => {}
        }
    }
}

fn notices_for(s: &Snapshot) -> Vec<String> {
    let mut n = Vec::new();
    if s.power.is_none() {
        n.push(if cfg!(target_os = "linux") {
            "power: RAPL energy counters are not readable by this user (root-only on recent kernels)".into()
        } else {
            "power: IOReport energy channels unavailable".into()
        });
    }
    if s.bandwidth.is_none() {
        n.push("memory bandwidth: no supported counters on this machine".into());
    }
    if s.gpu.is_none() {
        n.push("GPU: no supported GPU found (Apple Silicon, NVIDIA NVML or AMD amdgpu)".into());
    }
    if s.sensors.is_empty() {
        n.push("sensors: no temperature sources found".into());
    }
    n
}
```

```rust
pub fn draw(f: &mut Frame, app: &mut App) {
    let area = f.area();
    let t = app.theme.clone();
    f.render_widget(Block::default().style(Style::default().bg(t.bg).fg(t.fg)), area);
    if area.width < layout::MIN_W || area.height < layout::MIN_H {
        f.render_widget(Paragraph::new("terminal too small"), area);
        return;
    }
    let Some(snap) = app.snap.clone() else {
        f.render_widget(Paragraph::new("collecting first sample…"), centered(area, 30, 1));
        return;
    };
    let [header, body, status] = Layout::vertical([Constraint::Length(1), Constraint::Fill(1), Constraint::Length(1)]).areas(area);
    panels::header::render(f, header, &snap, &t, app.paused, app.interval_ms);

    let visible = app.visible();
    let zoom = app.zoomed.then_some(app.focus);
    for (id, r) in layout::compute(body, &visible, zoom) {
        let ctx = Ctx { snap: &snap, hist: &app.hist, theme: &t, focused: id == app.focus, zoomed: app.zoomed, idx: id.number() };
        match id {
            PanelId::AiWorkload => panels::ai::render_workload(f, r, &ctx),
            PanelId::AiRuntime => panels::ai::render_runtime(f, r, &ctx),
            PanelId::Cpu => panels::cpu::render(f, r, &ctx),
            PanelId::Gpu => panels::gpu::render(f, r, &ctx),
            PanelId::Memory => panels::memory::render(f, r, &ctx),
            PanelId::NetDisk => panels::netdisk::render(f, r, &ctx),
            PanelId::Sensors => panels::sensors::render(f, r, &ctx, &app.sensors),
            PanelId::Processes => panels::processes::render(f, r, &ctx, &mut app.procs, app.mode == Mode::Filter, app.details),
        }
    }

    let hints = match (&app.mode, app.focus) {
        (Mode::Filter, _) => "type to filter · Enter keep · Esc clear",
        (Mode::Confirm(..), _) => "y confirm · any other key cancel",
        (_, PanelId::Processes) => "Tab/1-8 focus · z zoom · / filter · s sort · t tree · k/K kill · p pause · ? help · q quit",
        (_, PanelId::Sensors) => "Tab/1-8 focus · z zoom · ↑↓ select · Space expand · p pause · ? help · q quit",
        _ => "Tab/1-8 focus · z zoom · +/- interval · p pause · ? help · q quit",
    };
    let line = match app.status_text() {
        Some(msg) => Line::from(Span::styled(format!(" {msg}"), Style::default().fg(t.warn).add_modifier(Modifier::BOLD))),
        None => Line::from(Span::styled(format!(" {hints}"), Style::default().fg(t.dim))),
    };
    f.render_widget(Paragraph::new(line), status);

    match &app.mode {
        Mode::Help => panels::help::render(f, centered(area, 70, 28), &t, &app.notices),

            let r = centered(area, 50, 5);

                ]),
                inner,
            );
        }
        _ => {}
    }
}

/// Renders one frame to text (used by `--dump` and tests).
pub fn dump(app: &mut App, w: u16, h: u16) -> String {
    let mut term = Terminal::new(TestBackend::new(w, h)).expect("test backend");
    term.draw(|f| draw(f, app)).expect("draw");
    let buf = term.backend().buffer().clone();
    (0..h).map(|y| (0..w).map(|x| buf[(x, y)].symbol().to_string()).collect::<String>().trim_end().to_string()).collect::<Vec<_>>().join("\n")
}

pub fn run(mut app: App, rx: Receiver<Snapshot>) -> anyhow::Result<()> {
    // ratatui::init enables raw mode + alternate screen and installs a panic hook that restores the terminal.
    let mut terminal = ratatui::init();
    let res = (|| -> anyhow::Result<()> {
        loop {
            while let Ok(s) = rx.try_recv() {
                app.on_snapshot(s);
            }
            terminal.draw(|f| draw(f, &mut app))?;
            if event::poll(Duration::from_millis(50))? {
                if let Event::Key(k) = event::read()?
                    && k.kind == KeyEventKind::Press
                {
                    app.on_key(k);
                }
            }
            if app.quit {
                return Ok(());
            }
        }
    })();
    ratatui::restore();
    res
}
```

```rust
use std::path::PathBuf;
use std::process::ExitCode;
use std::time::Duration;

use clap::Parser;
use lazytop::collector::{self, Collector, demo::DemoCollector};
use lazytop::config::{self, Config};
use lazytop::ui::{self, app::App, process, theme::Theme};

#[derive(Parser, Debug)]
#[command(name = "lazytop", version, about = "A lazy-style terminal system monitor for macOS (Apple Silicon) and Linux")]
struct Cli {
    /// Refresh interval in milliseconds (250–10000)
    #[arg(short, long)]
    interval: Option<u64>,
    /// Use synthetic data instead of reading the system
    #[arg(long)]
    demo: bool,
    /// Config file (default: ~/.config/lazytop/config.toml)
    #[arg(long)]
    config: Option<PathBuf>,
    /// Write diagnostics (missing sensors, IOReport channels) to this file
    #[arg(long)]
    log: Option<PathBuf>,
    /// Theme: dark, light or mono
    #[arg(long)]
    theme: Option<String>,
    /// Render one frame as text (WIDTHxHEIGHT, e.g. 160x48) and exit
    #[arg(long, hide = true, value_name = "WxH")]
    dump: Option<String>,
}

fn main() -> ExitCode {
    let cli = Cli::parse();
    let mut cfg = match Config::load(cli.config.as_deref()) {
        Ok(c) => c,
        Err(e) => {
            eprintln!("lazytop: {e:#}");
            return ExitCode::from(2);
        }
    };
    if let Some(i) = cli.interval {
        cfg.interval_ms = config::clamp_interval(i);
    }
    if let Some(t) = cli.theme {
        cfg.theme = t;
    }
    let theme = match Theme::by_name(&cfg.theme).map(|t| t.with_overrides(&cfg.colors)) {
        Some(Ok(t)) => t,
        Some(Err(e)) => {
            eprintln!("lazytop: {e:#}");
            return ExitCode::from(2);
        }
        None => {
            eprintln!("lazytop: unknown theme {:?} (dark, light, mono)", cfg.theme);
            return ExitCode::from(2);
        }
    };
    if let Some(p) = &cli.log
        && let Err(e) = lazytop::log::init(p)
    {
        eprintln!("lazytop: cannot open log {}: {e}", p.display());
        return ExitCode::from(2);
    }

    let mut collector: Box<dyn Collector> =
        if cli.demo { Box::new(DemoCollector::new(1)) } else { collector::system_collector() };

    if let Some(dim) = cli.dump {
        let Some((w, h)) = dim.split_once('x').and_then(|(w, h)| Some((w.parse().ok()?, h.parse().ok()?))) else {
            eprintln!("lazytop: --dump expects WIDTHxHEIGHT");
            return ExitCode::from(2);
        };
        let mut app = App::new(cfg, theme, None, Box::new(process::send_signal));
        app.on_snapshot(collector.sample());
        std::thread::sleep(Duration::from_millis(500));
        app.on_snapshot(collector.sample());
        println!("{}", ui::dump(&mut app, w, h));
        return ExitCode::SUCCESS;
    }

    let interval = Duration::from_millis(cfg.interval_ms);
    let (rx, ctl) = collector::spawn(collector, interval);
    let app = App::new(cfg, theme, Some(ctl), Box::new(process::send_signal));
    match ui::run(app, rx) {
        Ok(()) => ExitCode::SUCCESS,
        Err(e) => {
            eprintln!("lazytop: {e:#}");
            ExitCode::FAILURE
        }
    }
}
```

# lazytop

A lazy-style terminal system monitor for **macOS (Apple Silicon)** and **Linux**, written in Rust with [ratatui](https://ratatui.rs).

lazytop shows CPU efficiency/performance clusters, GPU / Media / Neural Engine, memory and memory bandwidth, network and disk, temperatures and fans, power, processes and a local-AI overview — without root.

## Features

- **CPU**: E/P cluster usage and frequency (Apple Silicon via IOReport; Intel hybrid via sysfs), per-core view when zoomed, braille history.
- **GPU / Media / ANE**: Apple GPU usage, MHz, watts and memory; ANE power; media bandwidth. Linux: NVIDIA (NVML) or AMD (amdgpu sysfs).
- **Memory**: wired / active / compressed / free, pressure, app memory, cached, swap; memory bandwidth when the chip exposes counters.
- **Network & disk**: per-interface rates, disk read/write rates, usage and totals since boot.
- **Sensors**: temperatures grouped by CPU / GPU / Battery / Disk (SMC on macOS, hwmon on Linux), fans.
- **Processes**: sort (CPU, MEM, PID, NAME), incremental filter, tree view, details, SIGTERM/SIGKILL with confirmation.
- **AI**: detects local runtimes (ollama, llama.cpp, MLX, LM Studio, vLLM) and estimates the largest Q4_K_M model that fits in free memory.
- **Power**: CPU / GPU / ANE / DRAM / system watts (Apple Silicon); RAPL on Linux when readable.
- Missing metrics show `—`; press `?` to see why.

## How metrics are read

- **macOS**: IOReport (the private framework `powermetrics` uses) for CPU/GPU residency, frequency and energy; IOKit SMC for temperatures and fans; `host_statistics64` and `sysctl` for memory; IOKit block storage statistics for disk. No `sudo` needed. IOReport and SMC are undocumented; values may be missing on future macOS versions.
- **Linux**: `/proc`, `/sys/class/hwmon`, `/sys/class/powercap` (RAPL), NVML, `/sys/class/drm` (amdgpu).
- **Both**: [sysinfo](https://crates.io/crates/sysinfo) for processes, network and disks.
